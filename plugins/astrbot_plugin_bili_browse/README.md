# astrbot_plugin_bili_browse · 刷 B 站

让她在空闲时段自己去 B 站看一会儿，读懂字幕，再随口跟你说一句。

**不发评论、不点赞、不发动态、不做视觉理解。**

## 它怎么跑

```
每 60 秒心跳（纯代码，零 token）
  ├─ 窗口内吗？（默认 9-12 / 17-21）
  ├─ 今天刷够了吗？（默认 2 次）
  ├─ 距上次刷 ≥ 4 小时吗？
  ├─ 主人最近 30 分钟在聊天吗？
  └─ 全过 → 问一次「现在想不想刷」→ 想才去
        搜 20 条 → 粗筛 5 条 → 读 3 条字幕 → 一次 LLM 生成一句话
        攒着，等你安静了再说（一次只说一件）
```

## 安装

1. 依赖已装进 AstrBot 的 venv：

```powershell
python -m pip install "bilibili-api-python>=17.4.1,<18"
```

2. 重启 AstrBot（或在 WebUI 里重载插件）。

3. 进 WebUI 插件配置，确认：
   - `windows` = `9-12,17-21`
   - `max_per_day` = 2
   - `asr_enabled` = **false**（第一周先关）

## 首次使用：扫码登录

字幕接口必须带登录态（未登录会抛 `CredentialNoSessdataException`）。在 QQ 里发：

```
/bili login
```

会收到一张二维码图片。**扫码之后，手机上必须点一下「确认登录」** —— 只扫码不确认，
状态会停在「已扫待确认」，插件会提示你一句。

确认时选「记住我 / 长期」。凭证保存在 `data/credential.json`，不上传任何地方。

> ⚠️ 旧版插件（v0.1.0 最初那版）用的是 `bilibili_api` 的扫码解析，实测会把 `sessdata`
> 抠成空串，表现为「扫码成功但一直说没登录」。**v0.1.1 起改成直接走 passport 接口**，
> 不再依赖那个解析。如果升级后还提示没登录，看下面这条兜底。

### 兜底：手动填 SESSDATA

在 WebUI 的插件配置里填 `sessdata`，然后重载插件。值从浏览器 F12 →
Application → Cookies → `bilibili.com` → `SESSDATA` 复制（**带 `%` 的原始值，不要解码**）。

填完重载插件，`/bili status` 里应显示「已登录」。

> 建议用小号。高频搜索会触发风控，主号被限了你日常刷视频也受影响。

## 命令

| 命令 | 作用 |
|---|---|
| `/bili` | 看状态（登录、窗口、今天刷了几次、攒着什么话） |
| `/bili now` | 立刻刷一次（手动，不占当天额度） |
| `/bili login` | 扫码登录 |
| `/bili on` / `/bili off` | 临时开关（重启后以配置为准） |
| `/bili say` | 清掉攒着还没说的话 |

## 配置项

| 键 | 默认 | 说明 |
|---|---|---|
| `windows` | `9-12,17-21` | 可刷时段，`起-止` 用逗号分隔 |
| `max_per_day` | 2 | 每天最多刷几次 |
| `min_gap_hours` | 4 | 两次之间至少隔几小时 |
| `keywords` | 空 | 手填关键词；留空则从最近对话自动生成 |
| `read_count` | 3 | 每次读几条字幕 |
| `subtitle_max_chars` | 1500 | 单条字幕截断（保头尾） |
| `max_video_minutes` | 15 | 超过这时长直接跳过 |
| `asr_enabled` | false | 没字幕时本地转写（需另装 asr.py + 环境） |
| `quiet_if_user_active_minutes` | 30 | 你多少分钟内说过话就不打扰 |
| `memory_days` | 3 | 聊天时注入「最近刷到过什么」的天数 |
| `memory_lines` | 6 | 注入块最多列几条 |
| `target_umo` | 空 | 留空自动从 `proactive_contact` 的启用会话里取 |
| `sessdata` | 空 | 扫码失败时手动填的兜底凭证 |

## 她怎么"记得"刷过什么

每次对话前，插件会往 system prompt 尾部加一小段（约 120 token）：

```
【你最近刷 B 站看到的】
· 今天傍晚：《【大会员不浪费】…》 by 某UP
· 昨天傍晚：《医学博士讲熬夜的危害》 by 歌白
今天已经刷过 1/2 次；17-21 这个时段已经用掉了，下次可刷是明天 9-12。
（这些你本来就知道，不用假装「查了记录」。细节记不清就直说记不清，别编；
  也不用主动提，话题对上了再说。）
```

两件事一起做才有用：

1. **投递出去的话写回对话历史** —— 否则她下次被问"你刷了吗"会答"天没说过"（10-24 实测过）。
2. **注入最近刷到的列表 + 状态** —— 只有列表没状态时，她会问"那今晚那次可以刷了吧"，
   因为她不知道 17-21 已经用掉了。

列表 5 分钟缓存，状态每次现算。

## 数据文件

都在插件目录 `data/` 下：

- `browse.db`：窗口状态、看过什么（判重）、每次刷的记录
- `credential.json`：B 站登录凭证
- `login_qr.png`：最近一次的登录二维码

## 回滚

这个插件**没有改任何现有文件**，删掉即可：

```powershell
Remove-Item -Recurse -Force '<AstrBot>/data/plugins/astrbot_plugin_bili_browse'
```

再把 `bilibili-api-python` 卸掉（可选）：

```powershell
-m pip uninstall -y bilibili-api-python
```

安装前的完整依赖基线备份在工作区：`pipfreeze-20261023-193455.txt`。

## 已知限制

- **没登录就没字幕**（`CredentialNoSessdataException`）。没登录时只能靠 ASR，而 ASR 默认为关 → 等于刷不到东西。
- 字幕覆盖率是未知数，第一周重点看日志里的「字幕命中 X/Y」。
- 只读字幕文本，不看画面。硬字幕（烧在画面里的）读不到。
- 一次刷只发一条消息，不刷屏。
- 搜索只取第一页（20~40 条），不翻页——翻页最容易被 -352。

## 验收要看什么

跑一周后看这四个数（都在日志里）：

1. `字幕命中 X/Y` —— 覆盖率，决定要不要开 ASR
2. `总耗时` —— 有字幕应 < 60 秒
3. `本次完成：读 N 条` —— 实际读到几条
4. 她说出来的原话 —— 像不像人话
