# astrbot_plugin_sticker — 表情包

让机器人在聊天中**自己判断**"这会儿发张图比打字更合适"，然后从对应情绪的分类里随机挑一张发出来。

它是通过大模型工具触发的——**用户不需要敲任何命令**，也不需要关键词触发。

## 依赖

- AstrBot 4.x
- **不需要第三方库**（只用标准库），也**不需要 API Key**

## 工作方式

```
对话进行中
   ↓
大模型读到 send_sticker 工具的说明，判断"现在这个情绪用图表达更合适"
   ↓
调用 send_sticker(emotion)
   ↓
冷却检查：距上次发表情是否已经隔够 N 轮
   ↓
从 stickers/<情绪>/ 里随机抽一张（同一情绪不连着抽同一张）
   ↓
发出去，并把结果返回给大模型，让它接着把话说完
```

几个设计上的说明：

- **冷却机制**：两次主动发表情之间至少隔 `cooldown_turns` 轮对话（默认 5 轮），避免刷图。
  注意这个计数是**全局**的，不是按会话分开算的。
- **防重复**：同一个情绪分类下，不会连着两次抽到同一张图。
- **目录自动创建**：`stickers/` 和五个情绪子目录会在插件启动时自己建好，不需要手动准备。
- **抽不到图也不报错**：某个分类空着时，工具会返回"这个分类下还没有表情包"，
  对话照常继续，不会中断。

## 情绪分类

| 目录 | 对应情绪 |
|---|---|
| `happy/` | 开心、高兴、兴奋 |
| `shy/` | 害羞、脸红、被戳中心事 |
| `angry/` | 生气、鼓脸、炸毛 |
| `sad/` | 难过、委屈、低落 |
| `smug/` | 得意、坏笑、捉弄人 |

图片放进对应目录即可，**文件名随意**（插件不看名字，只随机抽）。
支持 `png` / `jpg` / `jpeg` / `gif` / `webp`，并且要**直接放在情绪目录下**——插件不递归子目录。
详见 [`stickers/README.md`](stickers/README.md)。

## 配置

| 配置项 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `enabled` | bool | `true` | 总开关。关掉之后不会再主动发表情包 |
| `cooldown_turns` | int | 5 | 两次主动发表情之间至少间隔多少轮对话 |

## 命令

```
/sticker list        查看各情绪分类各有多少张
/sticker <情绪>      手动发一张（测试用，不占用冷却）
```

## 提供给大模型的工具

`send_sticker(emotion)` —— 参数只能填 `happy` / `shy` / `angry` / `sad` / `smug` 之一。

工具的说明文字里写清楚了「什么时候该用、什么时候不要用」（比如认真聊正事、
对方情绪低落需要好好说话时不要发），所以它判断得准不准，取决于这段说明和模型本身。

## 关于图片

本插件**不含任何图片**，`stickers/` 下的五个目录是空的——这是有意留空的，
请自行收集表情包放进去（也请注意图片版权）。
