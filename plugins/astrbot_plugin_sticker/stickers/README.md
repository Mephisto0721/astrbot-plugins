# 表情包目录

把表情包按情绪放进对应的子目录，机器人在觉得"这会儿发张图比打字更合适"时会自己挑一张发出来。

| 目录 | 对应情绪 |
|---|---|
| `happy/` | 开心、高兴、兴奋 |
| `shy/` | 害羞、脸红、被戳中心事 |
| `angry/` | 生气、鼓脸、炸毛 |
| `sad/` | 难过、委屈、低落 |
| `smug/` | 得意、坏笑、捉弄人 |

## 往里放图时注意

- **支持格式**：`png` / `jpg` / `jpeg` / `gif` / `webp`
- **文件名随意**，插件不看名字，只在目录里随机抽
- 图片要**直接放在情绪目录下**，插件**不递归子目录**（多套一层就找不到了）
- 同一情绪下，插件不会连着两次抽到同一张
- 目录不存在时插件会自己创建，所以本仓库里可以只留空目录

## 关于这里的 `.gitkeep`

Git 不跟踪空目录，所以每个情绪目录里放了一个 `.gitkeep` 占位，好让目录结构能出现在仓库里。
往目录里放好图片之后，这些占位文件就可以删掉了。
